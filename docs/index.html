Made for reading

  • Images across the full width

    Photos and figures break out of the text column: into the margins on the Mac, from edge to edge on iPhone.

  • Footnotes in place

    Footnotes from common blogs and newsletters open in a popover next to their marker instead of jumping to the end of the article.

  • A blue dot for updates

    When a new version of the Ringo theme is out, a blue dot appears on the R in the article header. Its settings install the update.

  • Colored code

    Code blocks are colored by their language, with a menu to pick another one and a button that copies the code.

  • Native fonts and colors

    San Francisco in the text size you chose, in colors that follow light and dark mode and meet the WCAG contrast ratio.

  • Embedded videos

    YouTube, Vimeo and other players fill the column at 16:9 instead of keeping a small fixed size.

Questions

How do I install the Ringo theme?

With Add to NetNewsWire on this page, or from the NetNewsWire Theme Marketplace:

  1. On the Mac, iPhone or iPad with NetNewsWire, choose Add to NetNewsWire and let your browser open NetNewsWire.
  2. NetNewsWire asks Install theme? with the theme’s name and author: choose Install Theme.
  3. Installing keeps your current theme, so pick the Ringo theme: on the Mac in Settings → General → Article Theme, on iPhone and iPad in Settings → Articles → Theme.

Updates come through the theme itself: a blue dot on the R in the article header shows a new version, and its settings install it.

Does the Ringo theme need JavaScript?

No, the Ringo theme stays readable without it. But only with Article JavaScript on in NetNewsWire does the theme check for new versions on GitHub, and tidy up articles for calm reading: it hides empty paragraphs and repeated titles, opens footnotes in place, colors code and shows the date in your language.

Where can I report a problem, suggest a feature or ask a question?

Open an issue on GitHub or write in the NetNewsWire forum. Ideas for new features and questions are welcome in GitHub Discussions.

Is the Ringo theme free?

Yes. Like NetNewsWire, the Ringo theme is free to download and use. Please mind its license, the Apache License 2.0.
